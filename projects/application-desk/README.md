# Application Desk

I am developing a browser-based job-application tracker as my personal project for Building Personal Apps with Claude: From Idea to Reality.

## Part 1

- Add, edit, and delete application records.
- Track statuses, deadlines, and notes.
- Search and filter applications.
- Save records in the browser and export CSV.

[Open Application Desk](https://hri-application-tracker.hritikaadhikary10.chatgpt.site) — access is controlled by the existing Site sharing settings.

## In progress

My next verification step is to add a test record, refresh, edit its status, export CSV, and delete the test record. Claude Desktop/MCP integration remains a later phase.
